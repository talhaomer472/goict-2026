# GOICT-2026 — Global Oil Import Cost Tracker

How much more did countries pay for crude oil because of the 2026
Middle East conflict?

GOICT-2026 measures the additional crude-oil import expenditure of
reporting economies relative to a pre-conflict Brent benchmark, using
reported import volumes and observed prices.
